# Browser Video Studio

Open [the video studio](https://artyomvorontsov.github.io/programming-forever-web/).

This repository contains only the published static website. Video rendering and
exports run in your browser. Configure your own provider keys in Settings; keys
and drafts stay in your browser profile. No API keys or generated videos are
included here.

Use a current browser with WebGPU and H.264/AAC encoding support.
